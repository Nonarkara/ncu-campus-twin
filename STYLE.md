# STYLE — NCU Campus Twin

Register: **Console** (dense, dark operator surface). Design Read: *a duty officer's clipboard laid over the campus plan. One number wins, then the list of decisions.* Reference artifact: the Vignelli 1972 diagram's discipline of hairlines on a dark field.

- Ground `#0a0e14`, ink `#e6edf3`, dim `#9aa7b4` (7.6:1 on ground), hairline `rgba(230,237,243,.14)`.
- One accent: amber `#f59e0b`. It means "act" or "more". Never decoration.
- Type: **Jost** (Latin) + **Noto Sans TC** (Traditional Chinese). Two families. Tabular numerals. Three sizes: 32 / 14 / 11.
- Radius 0, no shadows, no gradients. The map uses hairlines and one fill tone; the Power lens ramps amber by kWp.
- Grid: 400 px panel + map (≥ 60% of desktop width). Phone: one column, panel first because the decision list is the payload; map after.
- Controls: text tabs and toggles at 32 px (dense group, MSH ruling).
- Every number shows source · tier · age. Missing feeds show nothing, never zero.
